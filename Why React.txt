What is CSR and SSR?
CSR (Client-Side Rendering):-
In React apps, CSR means:
The browser a basic HTML file, and JavaScript builds the Ul on the client(Browser)
Flow:
1. Browser loads empty HTML
2. JS bundle loads
3. React renders Ul
Example:
• Normal React app (create-react-app, Vite)

• Pros
• Fast navigation after first load
• Smooth user experience (SPA)
• Less load on server
X Cons
• Slow initial load
• Bad for SEO (content not ready initially)

SSR: Server Side Rendering
SSR (Server-Side Rendering):-
SSR means:
HTML is generated on the server and sent to the browser.
Flow:
I. Request goes to server
2. Server renders HTML
3. Browser receives fully rendered page
Example:
• Next.js

Pros
• Fast initial load
• Great for SEO
• Better performance on slow devices
X Cons
• More server load
• Slower navigation (page reload)
• Complex setup

What is Redux?
State management library for large apps.
Central store + preedictable state updates
