What is a Set?
Definition: A built-in object/data structure that stores unique values of any type (primitive references or objects).
Key Rule: Duplicate values are not allowed. If you try to add an existing value, it gets ignored.
Hinglish Note: Ye array jaisa hi hota hai, par isme koi duplicate item nahi aa sakta. Har value sirf ek baar hoti hai.

How to create set:
// Khali Set banana
const mySet = new Set();
// Array se Set banana (Duplicates automatically remove ho jate hain)
const numbers = [1, 2, 2, 3, 4, 4];
const uniqueSet = new Set(numbers); 
console.log(uniqueSet); // Set(4) {1, 2, 3, 4}


Concept                                         Explanation                               Hinglish Note
new Set(array)                                  Creates a Set from Array                  Array se saare duplicates automatic hata deta hai
[...new Set(array)]                             Converts Set back to Array                Unique elements wala naya array ban jata hai


Quick example:
const numbers = [1, 2, 2, 3, 4, 4, 5];
// Array se duplicates hatane ka best tarika:
const uniqueNumbers = [...new Set(numbers)];
console.log(uniqueNumbers); // [1, 2, 3, 4, 5]
